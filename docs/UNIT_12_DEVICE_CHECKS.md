# 單元 12 真機聆聽檢查

給在 iPhone 上試聽的人。程式沒有為這些題目做特別畫面，標記只留在題目資料裡（`needsRealDeviceCheck: true`）。請用主畫面的「日文日誌」打開，進入單元 12，做到聆聽題時聽系統語音。

完整欄位說明見 [unit-n5-12.README.md](unit-n5-12.README.md)。

## 必須在真機確認的兩題

| 題目 id | 位置 | 要聽什麼 |
| --- | --- | --- |
| q-n5-12-024 | 第 2 課聆聽 | 「おばあさん」是否讀出長音（5 拍），和「おばさん」（4 拍）有明顯差別；「ば」是否是清楚的濁音，沒有變成「ぱ」或「は」 |
| q-n5-12-058 | 小測聆聽 | 同上。同一組詞，題目方向不同 |

## 其餘聆聽題

本單元的動詞沒有長音。其餘題目請確認發音清楚、速度適中：

- 第 1 課：q-n5-12-010、q-n5-12-011、q-n5-12-012
- 第 2 課：q-n5-12-022、q-n5-12-023（另加上面的 q-n5-12-024）
- 第 3 課：q-n5-12-035、q-n5-12-060、q-n5-12-037
- 故事：q-n5-12-044、q-n5-12-061、q-n5-12-046
- 小測：q-n5-12-057、q-n5-12-059（另加上面的 q-n5-12-058）

q-n5-12-036 與 q-n5-12-045 已從課程撤回，由 q-n5-12-060、q-n5-12-061 代替。舊的錯題紀錄若仍帶有這兩個編號，打開錯題本時會略過，不會報錯。

請順便記下：

1. 有沒有讀錯的詞，尤其是「かえる」「はいる」「はなす」。
2. 「ちょっと」的促音是否清楚。
3. 「わたしわ」是否自然。q-n5-12-046 要確認助詞「は」讀作「わ」。
4. q-n5-12-060 會在喇叭旁邊顯示漢字「帰る」，請選出讀音。q-n5-12-061 會在喇叭旁邊顯示「きょう帰る。」，請判斷動詞類別。
5. 若手機沒有日文語音，頂部橫幅可以關閉，而且只在這個分頁工作階段記住。沒有顯示題幹的聆聽題會出現「顯示文字」，按下後才看到句子。

## 版面（真機再看一次）

- 配對題的選單是否容易點，聚焦時頁面沒有被放大。
- 特大字體、較矮的螢幕上，答錯面板能否同時看到答案、讀音和規則。
- 沒有日文語音時，橫幅是否留在頁面內容裡，沒有蓋住離開鈕、進度或返回。
