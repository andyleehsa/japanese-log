# 設定步驟

這份說明給使用 iPhone Safari 的學習者。不需要寫程式。完成之後，每天從主畫面的「日文日誌」圖示打開即可。

你會做兩件事：打開網站，以及加到主畫面。學習進度只留在這部裝置，不會上傳。

## 1. 開啟網站

1. 用 Safari 打開：<https://github.com/andyleehsa/japanese-log/settings/pages>
2. 如果要登入，先登入你的 GitHub 帳號。
3. 見到 **Build and deployment**：
   - Source 選擇 **Deploy from a branch**
   - Branch 選擇 **main**
   - 旁邊的資料夾選擇 **/ (root)**
4. 按 **Save**。
5. 等一兩分鐘。網站地址是：<https://andyleehsa.github.io/japanese-log/>

如果還沒看到 Save，可以改用：打開 <https://github.com/andyleehsa/japanese-log> → **Settings** → **Pages** → **Deploy from a branch** → **main** → **/ (root)** → **Save**。

手機版有時要先按左上角選單，才看得到 Settings。

還沒打開 Pages 之前，網址會顯示 404。打開之後也可能要等幾分鐘。

## 2. 加到主畫面

請用 **Safari**，不要用 Chrome。

1. Safari 打開 <https://andyleehsa.github.io/japanese-log/>
2. 看到「日文日誌」，以及底部的 **學習**、**複習**、**我的**，就是打開正確了。
3. 按底部分享按鈕（一個正方形，上面有箭頭）。
4. 向下找 **加入主畫面**（英文是 **Add to Home Screen**）。
5. 名稱留 **日文日誌**，按 **加入**。
6. 回到主畫面，按新圖示打開。打開之後，上方不應該再看到 Safari 的網址列。

**之後請一直用主畫面的圖示。** 在 iPhone 上，Safari 分頁和「加入主畫面」之後的 app 是兩份儲存，練習紀錄不會互通。

第一次要有網絡。之後沒有網絡，仍然可以打開先前載入過的課程和你的紀錄。

## 3. 已經安裝舊版的人

如果主畫面裡已經有舊的「日文日誌」，第一次改開新版本時，請先連上網絡，打開圖示，然後等待大約 **10 分鐘**。接著把 app 完全關掉（從多工畫面滑掉），再重新打開，這樣做 **兩次**。

可以這樣確認已經是新版本：頁面是琥珀色，底部只有三項，**學習**、**複習**、**我的**。舊版本的練習紀錄不會帶過來，新版本從零開始計算。

GitHub Pages 不能由這個專案設定快取時間，所以更新要靠上面的步驟。程式會用新的快取名稱 `jpn5-shell-v4`，並在讀取檔案時跳過舊的網頁快取。

## 4. 進度存在哪裡

練習結果、錯題本、生詞的「認識 / 不認識」，以及字體大小，都只存在這部裝置。沒有同步按鈕，也不需要金鑰。

換手機或刪除主畫面圖示之後，這些紀錄不會自動出現在另一部裝置。
