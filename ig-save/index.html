IG存相 — 安裝

用 Safari 開呢頁。跟四步就得。唔使 Google Docs。

第 1 步

裝 Scriptable（免費）

  1. 撳下面掣去 App Store
  2. 裝Scriptable（免費嗰個）
開 App Store 裝 Scriptable
第 2 步

複製腳本入 Scriptable

  1. 撳大掣「複製腳本」
  2. 打開 Scriptable → 右上 ＋
  3. 長按空白位 → 貼上
  4. 名稱改成正好：IG存相解析
  5. 撳 Done 儲存
⚠️ 名要一字唔差：IG存相解析
中間唔可以有空格！

複製完會顯示「已複製」。下面細框係後備，唔使睇。

第 3 步

加入捷徑「IG存相」

  1. 撳下面掣下載簽名捷徑
  2. 用 Safari 下載 → 去「檔案」App 搵到檔
  3. 撳檔 → 加入捷徑
  4. 打開捷徑 → 撳「IG存相」→ ⓘ → 打開在分享表單中顯示
下載捷徑「IG存相」

如果問權限，選「一律允許」。

第 4 步

平時點用

IG 貼文 → 分享（紙飛機）→ 揀 IG存相 → 等幾秒 → 相入相簿。

只存相（單相／輪播）。Reel／片會略過。第一次可能要喺 Scriptable 登入 IG 一次。

搞唔掂？確認腳本名係 IG存相解析（無空格），捷徑名係 IG存相。
