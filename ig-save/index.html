IG存相 — 安裝

版本 1.5。用 Safari 開呢頁。最穩陣係複製連結之後，喺 Scriptable 撳播放。

你之前裝過嘅話，一定要先做呢三樣，否則會仲係舊問題：
  1. 打開「捷徑」App，刪走舊嘅「IG存相」
  2. 呢頁拉下刷新
  3. 腳本要見到 1.5.0-ig-photos，再重新下載裝捷徑
第 1 步

裝 Scriptable（免費）

  1. 撳下面掣去 App Store
  2. 裝Scriptable（免費嗰個）
開 App Store 裝 Scriptable
第 2 步

複製腳本入 Scriptable

  1. 撳綠色大掣「複製腳本」
  2. 打開 Scriptable → 右上 ＋
  3. 長按空白位 → 貼上
  4. 名稱改成正好：IG存相解析
  5. 撳 Done 儲存
⚠️ 名要一字唔差：IG存相解析
中間唔可以有空格！
貼上之後，頭幾行要見到 1.5.0-ig-photos。見唔到就刷新再複製一次。

複製完會顯示「已複製」。下面細框係後備，唔使睇。

第 3 步

最穩陣方法（唔經捷徑）

複製連結 → 打開 Scriptable → 撳播放撳「IG存相解析」上面嘅播放掣。第一句要係「IG存相 1.5.0-ig-photos」。見到相就撳完成。
  1. 喺 IG 撳「複製連結」
  2. 打開 Scriptable（唔好開捷徑）
  3. 撳 IG存相解析 嘅播放

輪播同單張都用呢條。會先彈腳本版本，跟住打開 IG 頁存相。

第 4 步

捷徑「IG存相」（可選）

  1. 確認舊嘅「IG存相」已經刪咗
  2. 撳下面掣下載，用 Safari 去「檔案」App 搵到檔
  3. 撳檔 → 加入捷徑
  4. 撳「IG存相」→ ⓘ → 打開在分享表單中顯示
下載捷徑「IG存相」

單張相：IG 分享 → IG存相，有機會直接入相簿。輪播分享通常冇相亦都冇連結，要先複製連結。複製連結後可以喺「捷徑」App 再撳一次「IG存相」，會彈「即將打開 Scriptable」同條連結。如果捷徑閃一下就冇嘢，用第 3 步播放。

第一次問「允許儲存相片」，撳允許。

搞唔掂？確認腳本名係 IG存相解析（無空格），捷徑名係 IG存相，而且你刪咗舊捷徑再裝。

已複製 ✓
